# iDrama.ai

Responsive short-drama discovery website for the **iDrama.ai** brand.

## Features
- Responsive desktop/mobile layout
- Search and category filters
- AI Drama, live-action, and animation sections
- Popular ranking panel
- Clickable drama detail modal with episode selector
- Static hosting friendly (GitHub Pages / Vercel / Render)

## Local use
Open `index.html` directly in a browser or serve this repository with any static HTTP server.
